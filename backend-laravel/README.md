# منصة نوح التعليمية (Nohe Academy) - Laravel 11 Backend API

حزمة الخادم الخلفي المتكاملة والمبنية وفق أحدث معايير **Laravel 11.x (PHP 8.3)** لدعم منصة نوح التعليمية الموجهة لطلاب مسارات الثانوية العامة واختبارات القدرات والتحصيلي في المملكة العربية السعودية.

---

## 🛡️ مصفوفة الأمان والتحقق الخماسي الإلزامي (Security Checklist)

| المطلب الأمني | حالة التنفيذ | آلية التحقق في الكود |
|---|---|---|
| **1. التدفقات الأربعة كاملة (All 4 Auth Flows)** | ✅ مكتمل | تسجيل جديد (`POST /register`)، دخول (`POST /login`)، خروج وإلغاء صلاحية التوكن (`POST /logout`)، واستعادة كلمة المرور (`POST /forgot-password` & `POST /reset-password`). |
| **2. تشفير كلمات المرور (Password Hashing)** | ✅ مكتمل | تشفير إلزامي بمكتبة `Bcrypt` عبر `Hash::make()`، مع منع تخزين أي كلمة مرور صريحة، واستبعاد حقل `password` من مخرجات JSON (`$hidden`). |
| **3. انتهاء صلاحية الجلسات (Inactivity Timeout)** | ✅ مكتمل | ضبط مدة الصلاحية على 1440 دقيقة (24 ساعة) في `SESSION_LIFETIME` وتوكنات Sanctum عبر `SANCTUM_EXPIRATION=1440`. |
| **4. حماية المسارات (Route Protection)** | ✅ مكتمل | تطبيق وسيط `auth:sanctum`، وسياسات الترخيص (مثل `LessonPolicy`) لحظر الوصول غير المصرح لروابط الدروس والفيديوهات والاختبارات. |
| **5. الحد من معدل المحاولات (Rate Limiting & Lockout)** | ✅ مكتمل | قفل محاولات الدخول تلقائياً بعد **5 محاولات فاشلة** لكل (بريد/جوال + IP) مع حظر لمدة دقيقة وتصاعد زمني عبر `RateLimiter`. |

## 🗄️ هيكل البيانات (Data Model)
تم بناء 16 جدولاً وقيداً مع تكامل كامل لمسارات الثانوية العامة السعودية:
1. `users`: بيانات الطلاب والمعلمين والمشرفين مع حقول مسارات الثانوية (`grade_level`, `track`).
2. `teachers`: السير الذاتية والتخصصات وألوان الهوية (`banner_color_theme`).
3. `subjects`: المواد الدراسية المعتمدة من وزارة التعليم وقياس.
4. `courses`: المساقات التعليمية مع الأسعار بالريال السعودي (SAR).
5. `lessons`: الدروس ومفاتيح Bunny.net Stream المشفرة وروابط المذكرات المرفقة (PDF).
6. `packages`: الباقات الفصلية والسنوية المجمعة.
7. `package_course`: جدول الربط المتعدد بين الباقات والمقررات.
8. `orders`: سجلات الشراء عبر بوابات الدفع السعودية (مدى، STC Pay، أبل باي).
9. `enrollments`: اشتراكات الطلاب المعتمدة وتواريخ انتهاء الصلاحية.
10. `questions`: بنك الأسئلة الموحد مع خيارات JSON ومؤشر الإجابة الصحيحة وشرح المعلم.
11. `exams`: الاختبارات الدورية والتجريبية والمحاكية للتحصيلي والقدرات.
12. `exam_question`: ترتيب الأسئلة في كل اختبار.
13. `exam_attempts`: توثيق درجات وإجابات الطلاب المحسوبة من جانب الخادم فقط.
14. `progress_reports`: تقارير الإنجاز الأسبوعية للطلاب وأولياء الأمور.
15. `support_tickets`: تذاكر الدعم الفني والأكاديمي (واتساب، تيليجرام، داخل المنصة).
16. `rewards`: نقاط التحفيز ونظام المكافآت والأوسمة.

## 🚀 دليل النشر على خادم Hostinger VPS

### الخطوة 1: تهيئة الخادم الآلي
قم بالدخول إلى الخادم عبر SSH وشغّل سكريبت التهيئة التلقائي:
```bash
bash deploy/hostinger-setup.sh
```

### الخطوة 2: استنساخ ونشر الكود
```bash
sudo mkdir -p /var/www/nohe-api
sudo chown -R $USER:www-data /var/www/nohe-api
cd /var/www/nohe-api
git clone <YOUR_REPO_URL> .
composer install --no-dev --optimize-autoloader
cp .env.example .env
php artisan key:generate
```

### الخطوة 3: إعداد قواعد البيانات وتوليد البيانات الأولية
```bash
# عدل بيانات قاعدة البيانات في ملف .env ثم شغّل:
php artisan migrate --seed --force
```

### الخطوة 4: تفعيل Nginx وشهادة SSL المجانية
```bash
sudo cp deploy/nginx-nohe.conf /etc/nginx/sites-available/nohe-api
sudo ln -s /etc/nginx/sites-available/nohe-api /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d api.noheacademy.sa
```

### الخطوة 5: تشغيل قائمة الانتظار الخلفية (Supervisor)
```bash
sudo cp deploy/supervisord-queue.conf /etc/supervisor/conf.d/
sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start nohe-worker:*
```

## 💡 التوصيات المعمارية لقرارات ما قبل الإطلاق (Decisions)

1. **صلاحية الاشتراك (Lifetime vs Per-Term):**
   - **التوصية:** اعتماد انتهاء الصلاحية الفصلي (`Per-Term` مع ربطه بتاريخ نهاية الفصل الدراسي الوزاري + 14 يوماً إضافية لمراجعة الاختبارات النهائية). هذا النموذج يضمن دورة إيرادات متكررة ويسمح للطلاب بالتجديد للفصول اللاحقة.
2. **بوابة الدفع المفضلة في السعودية (Moyasar vs HyperPay):**
   - **التوصية:** البدء ببوابة **ميسر (Moyasar)** لسرعة التفعيل، وضوح التوثيق البرمجي، ودعمها المباشر لبطاقات مدى وأبل باي وSTC Pay ونظام سداد، مع تكلفة اشتراك شهرية صفرية مقارنة بهيبرباي.
3. **التحقق برمز OTP عبر الجوال:**
   - **التوصية:** تفعيل بوابة رسائل محلية مرخصة من هيئة الاتصالات (مثل **Taqnyat** أو **Unifonic**) بتكلفة منخفضة لكل رسالة (حوالي 0.08 ريال)، مع توفير بديل مجاني عبر رسائل البريد الإلكتروني.
4. **حماية الفيديوهات من التسريب:**
   - تم تضمين طبقة علامة مائية ديناميكية شفافة (`Dynamic Watermark`) في كود الخادم تعرض اسم الطالب ورقم جواله المشفر وتاريخ الجلسة متحركة على مشغل Bunny Stream لمنع تسجيل الشاشة.
5. **التعامل مع النظام المسارات الجديد والنظام القديم:**
   - يدعم حقل `track` كلاً من المسار العام ومسار الحوسبة والهندسة ومسار الصحة والحياة ومسار إدارة الأعمال والمسار الشرعي، مع إمكانية إضافة مساري (علمي / أدبي) لطلاب السنوات السابقة عبر توسيع `track` بسهولة.
